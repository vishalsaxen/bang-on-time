Getting a GitHub access token (once)

  1. Open GitHub > New fine-grained token.
  2. Name it Bang On Time upload and pick an expiry.
  3. Repository access: Only select repositories > bang-on-time.
  4. Repository permissions: Contents = Read and write, Secrets = Read and write.
  5. Generate it, copy it, paste it in step 1 above and press Check.

Your list is saved as a private repository secret, so phone numbers never appear in the public repo. The image is saved in the repo as cloud-sender/image.jpg. Each upload replaces the previous list. A row that was already sent is not sent again if you upload it again.
